# Hackénia RPG — Prototype 0.1

Premier prototype jouable dans un navigateur.

## Tester localement
Ouvrir `index.html` dans un navigateur.

## Mettre sur GitHub Pages
1. Créer un dépôt GitHub.
2. Ajouter `index.html`, `style.css` et `script.js`.
3. Aller dans **Settings → Pages**.
4. Choisir **Deploy from a branch**, puis la branche `main` et le dossier `/root`.
5. Enregistrer. GitHub fournira l'adresse du site.
